## Known gotchas

- **Background tasks need their own DB session.** `app/routers/documents.py`'s
  `_process_document_isolated` opens a fresh `SessionLocal()` rather than reusing the
  request-scoped session, because FastAPI may close the request session before a
  `BackgroundTasks` job actually runs. Reusing the request session here is a real,
  easy-to-reintroduce bug.
- **Repo-suggestion embedding is hard-locked to local Ollama in code**, not just by
  config convention — there is no `embedding_provider` setting. `LLM_PROVIDER=anthropic`
  (used for circular classification) has zero effect on the repo-indexing path. This is
  intentional (decisions.md #11) because that path can touch a confidential local
  codebase; do not add a cloud-embedding option without re-reading that decision first.
- **`REPO_SUGGESTION_ENABLED` defaults to `false`**, including in `render.yaml` for the
  deployed instance. This is a safety default, not an incomplete feature — don't flip it
  on for a shared/public deployment.
- **SQLite is the default `DATABASE_URL`**, including on the deployed Render instance,
  where disk is also ephemeral (does not survive redeploys/restarts). Fine for a demo;
  see decisions.md #14 before assuming persistence works there.
- **No auth anywhere**, on the API or the UI — an explicit, documented, reversible
  decision for this submission (decisions.md #13), not an oversight. Reverts to a blocker
  immediately if this is ever used beyond a graded demo.
- **The `.python-version` pin is load-bearing for deploys**, not a style preference — see
  the Commands section above and decisions.md #15. Don't remove it to "simplify."
